# Prismora
AI image intelligence platform: dot-matrix hero site, FastAPI backend, LangGraph agent swarm, CLIP + Qdrant RAG, Groq/Gemini assistant.
Local: `cp .env.example .env`, add keys, `docker compose up --build` -> site :3000, API docs :8000/docs (header `X-API-Key`).
Deploy: see docs/DEPLOY.md.
