Security and limits built in.


Upload integrity
50 MB cap, magic-byte verification, EXIF stripping.
Rate limiting
Token bucket per API key, with usage metering by pixels and tokens.
Access control
Role-based access (admin, editor, viewer) per tenant.
Provenance
C2PA metadata on AI outputs and a deepfake risk score on inputs.
GPU hygiene
VRAM is released after every job, with CPU fallback when no GPU is present.
Keys stay yours
The chat assistant keeps your Groq or Gemini key in this tab only.
